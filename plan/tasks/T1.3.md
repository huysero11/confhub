## 1. Mục tiêu

Sau task này chạy `npm run dev` trong `fe/` là mở được trang ConfHub ở `http://localhost:5173`:
có **header Shell B**, nút **đổi sáng / tối** và **đổi tiếng Việt / Anh** (nhớ lựa chọn sau khi tải

Đây là task dựng nền mà mọi màn hình sau dùng lại:

- Router có layout lồng nhau: thêm màn hình mới chỉ là thêm 1 route con.
- Bộ lệnh kiểm tra: `lint`, `typecheck`, `test`, `build`.

### Kiến trúc frontend (áp dụng cho mọi task FE từ đây)

Chia theo **nhóm chức năng**, trong mỗi nhóm đi theo các lớp, lớp trên chỉ gọi lớp ngay dưới:

```
page (trang, gắn với 1 route)      features/<nhóm>/pages/
  → component (khối giao diện)     features/<nhóm>/components/
    → hook (useQuery / useMutation, trạng thái)   features/<nhóm>/hooks/
      → api (hàm gọi 1 endpoint của BE)           features/<nhóm>/api.ts
        → apiClient (fetch chung: địa chỉ gốc, token, đổi lỗi)   lib/apiClient.ts
types (kiểu request / response, khớp DTO của BE)  features/<nhóm>/types.ts
```

- **Không có lớp `service` riêng giữa api và hook.** Với TanStack Query, hook đã lo phần gọi, cache,
  trạng thái tải / lỗi; hàm api đã là "một việc với BE". Lớp service ở giữa chỉ gọi chuyển tiếp.
  Logic không gắn với React (vd giữ và làm mới access token) đặt ở `lib/`, không gọi là service.
- Component không gọi `api` trực tiếp, page không viết `fetch`; hook không trả JSX.
- Thứ dùng chung nhiều nhóm: `components/` (khối giao diện), `layouts/` (shell), `lib/` (tiện ích),
  `theme/`, `i18n/`. Thứ chỉ một nhóm dùng thì nằm trong `features/<nhóm>/`.
- T1.3 chưa gọi API nên **chưa tạo** `features/`, `lib/`; T1.2 tạo `features/auth/` và
  `lib/apiClient.ts` theo đúng sơ đồ trên.

### Comment đầu file (bắt buộc với mọi file trong `fe/src`)

Mỗi file mở đầu bằng 2–5 dòng comment tiếng Việt: **file này là gì, chứa những gì, ai dùng nó**
(và nó thuộc lớp nào trong sơ đồ trên). Ví dụ:

```ts
// ThemeProvider — giữ chế độ sáng / tối của cả ứng dụng.
// Chứa: context + provider (đọc lựa chọn đã lưu hoặc theo hệ điều hành, bọc ConfigProvider của antd).
// Dùng ở: app/AppProviders.tsx. Component khác đọc / đổi chế độ qua hook useThemeMode.
```

File cấu hình (`vite.config.ts`, `eslint.config.js`) cũng có 1–3 dòng nói nó cấu hình gì. File JSON
không có comment thì mô tả trong mục 9.

### Giao diện: token và nền sáng / tối

- `themeTokens.ts`: token chung `fontFamily` (Be Vietnam Pro), `fontSize: 15`, `borderRadius: 8`;
  màu theo bảng PROJECT.md mục 9 cho từng nền — `colorPrimary`, `colorBgLayout` (nền),
  `colorBgContainer` (bề mặt), `colorText`, `colorTextSecondary`, `colorBorder`, `colorWarning`,
  `colorError`, `colorSuccess`.
- `ThemeProvider`: chế độ `'light' | 'dark'`.
  - Lần đầu: theo hệ điều hành (`prefers-color-scheme`). Người dùng đổi thì lưu `localStorage`
    khóa `confhub.theme` và từ đó dùng giá trị đã lưu.
  - Bọc `ConfigProvider` với `algorithm` = `darkAlgorithm` / `defaultAlgorithm`, `cssVar: true`,
    token của nền tương ứng, `locale` theo ngôn ngữ hiện tại.
  - Gán `data-theme="light|dark"` lên `<html>` (cho CSS riêng về sau và cho test).
- **Không gõ màu / số pixel trong component**: lấy từ `theme.useToken()`; bố cục dùng `Layout`,
  `Flex`, `Space` của antd. Ngoại lệ duy nhất: `themeTokens.ts` (nơi khai) và `global.css`.

### Song ngữ

- `i18n.ts`: tài nguyên `vi`, `en`; ngôn ngữ ban đầu = `localStorage` khóa `confhub.lang` → nếu chưa
  có thì `vi` khi trình duyệt là tiếng Việt, ngược lại `en`; `fallbackLng: 'vi'`.
  Đổi ngôn ngữ: lưu `localStorage`, gán `<html lang>`.
- Khóa dịch theo nhóm màn hình, vd `shell.themeToLight`, `shell.themeToDark`, `shell.language`,
  `home.title`, `home.subtitle`, `notFound.title`, `notFound.backHome`.
  **Không có chữ hiển thị nào viết thẳng trong component** (kể cả `aria-label`, `title`).
- `vi.json` và `en.json` phải có **cùng bộ khóa** (có test kiểm).

### Shell B và các trang

- `ShellBHeader` (theo `docs/ui/g1-account.html`): trái là logo chữ "ConfHub" (link về `/`), phải là
  `LanguageToggle` và `ThemeToggle`. Nền `colorBgContainer`, viền dưới `colorBorder`.
- `ShellB`: `Layout` cao tối thiểu toàn màn hình; nội dung canh giữa, rộng tối đa theo token, co
  giãn được tới màn hình điện thoại (360px) không vỡ.
- `HomePage`: tiêu đề + 1 dòng mô tả (i18n) — trang tạm tới G4.
- `NotFoundPage`: `Result status="404"` của antd + nút về trang chủ.
- `ThemeToggle`, `LanguageToggle`: `Button` có icon và `aria-label` (i18n), dùng được bằng bàn phím.
